# Wantedly copy

**タイトル**

高校SSH課題研究「災害時避難経路アプリ」の独立再実装

**期間**

2022年（高校在学中）／2026年にクリーンルーム再実装

**所属**

東京工業大学附属科学技術高等学校 情報システム分野（現・東京科学大学附属科学技術高等学校）

**URL**

https://github.com/sean-from-japan/two-stage-evacuation-router

**説明**

高校のグループSSH課題研究で、GIS情報と端末位置を利用し、①ハザードエリアからの脱出、②避難所への到達、の二段階でダイクストラ法を適用するAndroid/Java・Flask構成の避難経路アプリを開発しました。私はシステム設計と実装を担当し、アルゴリズム選定とアプリ化はグループで議論して決定しました。

公開リポジトリは当時の提出物ではなく、検証できた二段階の考え方を2026年に新規コードと合成データだけで再実装したものです。最寄り出口を先に固定せず、出口から避難所までを含む総距離で選択し、到達不能・危険区域内・利用対象外の候補を理由付きで説明します。Dijkstraを独立したBellman-Ford実装と照合し、小規模グラフでは全単純経路列挙とも比較しています。
